## What is CometChat UI Kit?

CometChat Android UI Kit provides ready-to-use chat UI components for integrating messaging functionality into Android applications. Built on top of the CometChat SDK, it offers a complete set of customizable components for conversations, messages, users, groups, and calls.

## Architecture

The UI Kit follows the MVVM (Model-View-ViewModel) architecture pattern:

- **View Components** - Custom Views extending `MaterialCardView`
- **ViewModels** - Android ViewModel with LiveData for state management
- **Adapters** - RecyclerView adapters for list-based components
- **Event System** - Listener patterns for component communication
